# v0.0.16rc1 -- Desktop Interaction Hardening

## Overview

This release continues the desktop product hardening work after
v0.0.15rc1. It focuses on replacing visible mock surfaces with real API
contracts, improving session/message fidelity, and documenting the local
development workflow.

## Desktop Runtime

- Desktop renderer development port is configured as `19999`. If the target
  port is occupied, electron-vite may auto-increment to the next available
  port during local development.
- Web console development port is configured as `9999`.
- Daemon remains on `127.0.0.1:8765`.

## User-Facing Changes

- Connectors now load from `/api/connectors` instead of showing mock GitHub
  and Gmail accounts.
- The connector API currently returns a real empty collection until connector
  persistence is implemented.
- Schedules can be deleted from the desktop schedules panel.
- The desktop API client supports DELETE through both browser fallback and
  Electron IPC.
- Session and message handling now includes richer persisted tool/thinking
  events and improved renderer message mapping.
- Desktop session creation improvements are included through the sidebar
  modal work.

## Backend/API

- Added `forge/api/routers/connectors.py`.
- Registered `/api/connectors`.
- Added integration coverage for connectors and schedule deletion.

## Verification

- `pytest`
- `pytest tests/integration/test_api_desktop.py`
- `cd desktop && npm.cmd run build`
- Desktop renderer smoke test against the active electron-vite port

## Notes

- Connector persistence and OAuth setup remain future work.
- Schedule creation from the desktop UI remains future work; schedule delete,
  pause, resume, refresh, and list are now wired to real APIs.
