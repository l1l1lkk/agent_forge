# v0.0.15rc1 -- Desktop QA Hardening

## Overview

Desktop QA hardening release focused on new workspace panels,
IPC/API error handling improvements, and integration test coverage.

## Desktop Workspace Panels

- **GitWorkspacePanel** -- Git workspace status and diff viewer for
  the desktop app.
- **DiagnosticsPanel** -- Enhanced diagnostics surface with expanded
  runtime visibility.
- **ConnectorsPanel** -- New connectors management panel.
- **SettingsPanel** -- Dedicated settings interface.
- **SchedulesPanel** -- Schedules management surface.

## Error Handling Hardening

- IPC layer (`desktop/src/main/ipc.ts`): improved error propagation
  and handling for renderer <-> main communication.
- API client (`desktop/src/renderer/api/client.ts`): hardened
  request/response error handling and timeout management.
- Desktop API router (`forge/api/routers/desktop.py`): expanded
  endpoints with structured error responses and health/diagnostics
  data.

## Testing

- `tests/integration/test_api_desktop.py` -- integration test coverage
  for the desktop API endpoints.
